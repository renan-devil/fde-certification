| oss-ventures-on-dark.svg / .png | Dark backgrounds only, designed for #141313 | https://www.oss.ventures (site header asset) |

The OSS Ventures file is the reversed (white) version: its dark triangles are meant to read as
cut-outs against #141313. There is no light-background OSS file here, so the site places both logos
on an #141313 band. Do not recolor or redraw either logo. PNGs are 1600 px wide, transparent,
rendered from the SVGs for use in the PDF certificate.
